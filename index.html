Welcome to Spark

A prototype built for this workshop. It turns a one-sentence treasury idea into something you can click. It suggests; it never decides.

  1. Type or dictate one sentence: “I wish something watched X and told me Y.”
  2. Watch it think, on the record.
  3. It stops and asks you two design decisions.
  4. You get a clickable prototype. Download it, or ask for a v2.

Settings

Demo mode runs fully offline with a built-in engine, so the workshop never depends on the network. Live modes send each step to a model API from this browser and fall back to the offline engine on any failure.
